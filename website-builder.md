Build a high-end, conversion-focused marketing website for a service called “Vibe Check Kits.”

This is NOT a generic website. It should feel like a premium design/creative studio landing page with strong motion design, modern typography, and immersive interactions.

========================
GOAL
========================
The site sells a service that builds high-converting websites for business owners and freelancers to generate leads and outperform competitors.

Primary CTA: “Book a Free Consultation”

The design should feel:

- Premium
- Modern
- Minimal but bold
- Motion-rich (Apple / Awwwards-inspired)
- Conversion focused

========================
TECH STACK
========================
Use:

- HTML, CSS, JavaScript OR React (prefer React if needed)
- GSAP (for animations)
- ScrollTrigger plugin
- Lenis (for smooth scrolling)
- Any lightweight utility for cursor + parallax effects

Do NOT use generic templates or basic Bootstrap-style layouts.

========================
MUST-HAVE INTERACTIONS
========================

1. Smooth Scroll

- Implement Lenis or equivalent
- Must feel buttery and controlled

2. Custom Cursor

- Cursor replaces default mouse pointer
- Expands on hover over buttons/links
- Slight lag for smooth trailing effect

3. Animated Page Loader

- Full-screen intro animation
- Kinetic typography reveal of:
  “Vibe Check Kits”
- Smooth transition into homepage

4. Scroll-Triggered Stagger Animations

- Sections animate in as user scrolls
- Use GSAP ScrollTrigger
- Text and cards should stagger in (not all at once)

5. Micro Interactions

- Buttons scale slightly on hover
- Links underline animates in
- Cards tilt slightly on hover (3D feel)
- Subtle glow or shadow changes on interaction

6. Kinetic Typography

- Hero headline should animate word-by-word or letter-by-letter
- Include subtle movement on scroll (parallax text shift)

7. Mouse-Driven Parallax

- Background elements shift slightly based on cursor position
- Depth layers (foreground / mid / background movement)

========================
PAGE STRUCTURE
========================

1. Loader Screen

- Animated brand name: “Vibe Check Kits”
- Subtext: “Building websites that generate clients”
- Smooth fade into site

2. Hero Section

- Headline (kinetic typography):
  “Turn Your Website Into a Client-Generating Machine”
- Subheadline:
  “High-converting websites for business owners and freelancers”
- CTA button: Book a Free Consultation
- Background: subtle animated gradient + parallax shapes

3. Problem Section

- Split layout
- Animated cards describing:
  - Losing leads without a website
  - Low trust / credibility issues
  - Losing clients to competitors

4. Solution Section

- Explain Vibe Check Kits system
- Include animated icon cards
- Stagger reveal on scroll

5. Services / Deliverables

- 4 cards:
  - Website Design
  - Landing Pages
  - Lead Capture Systems
  - Portfolio & Trust Sections
- Each card has hover animation + tilt effect

6. Pricing Section

- 3 pricing tiers:
  Starter ($499)
  Growth ($999) — highlight as “Most Popular”
  Premium ($1,999)
- Pricing cards should animate in with stagger

7. Results Section

- Bold typography
- Animated counters or emphasis text:
  “More Leads. More Trust. More Clients.”

8. CTA Section

- Strong closing statement:
  “Stop losing clients to competitors with better websites.”
- CTA button repeated

9. Footer

- Minimal, clean, modern

========================
DESIGN DIRECTION
========================

- Dark or near-dark theme preferred
- Accent color: electric blue / neon green / or warm orange (choose one consistent palette)
- Use large typography and spacing
- Use modern fonts (Inter, Satoshi, or similar)
- Avoid clutter
- Focus on hierarchy and motion

========================
IMPORTANT RULES
========================

- Do NOT create a static or boring layout
- Every section must have motion or interaction
- Avoid generic SaaS template look
- Prioritize premium feel over complexity
- Make it feel like a high-end design agency site
- Ensure smooth performance (no janky animations)

========================
OUTPUT
========================
Return complete working code with:

- index.html (or App.jsx if React)
- styles.css (or styled components)
- script.js (or animation hooks)

Everything should run cleanly when opened locally.
